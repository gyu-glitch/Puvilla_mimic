## 구현에 적용하는 기준

- 18–19쪽: 흰 털, 몸 비율, 눈·코·입의 형태와 배치를 유지한다. 2D 비율 도식을 임의로 3D 관절 길이로 환산하지 않는다.
- 24쪽: 서 있는 3D 정면·사선·측면·후면이 기본 형태다. 둥근 배, 부드러운 어깨, 손으로 갈수록 완만히 가늘어지는 팔, 작은 엄지를 유지한다. 기본 팔은 몸에서 약간 벌어진 A자 자세다.
- 25쪽: 앉은 모델의 형태도 확인했지만 현재 작업은 서 있는 원본을 사용한다.
- 31–33쪽: 3D 흰색은 RGB 242/242/242. Cinema 4D 털·재질 수치는 그 렌더러의 설정이다. WebGL 셸의 길이·거칠기 등에 그대로 대입하지 않는다. 현재 공개본 털의 기준을 유지한다.
- 36–37쪽: 신체나 얼굴 비율을 늘이거나 찌그러뜨리지 않는다. 목도리 등 기본 요소를 유지한다.
- 44–50쪽 및 52쪽: 공식 3D 동작 예시에서도 어깨–위팔–아래팔이 부드럽게 이어지고 손의 크기가 유지된다. 작은 엄지와 완만한 팔꿈치를 확인했다. 손인사 3D 원본 포즈가 제공된 것은 아니다. 인사 제스처는 사용자 이미지 `7629.png`를 참고하고, 형태는 공식 3D 기준을 따른다.

`18ee1aacbd91b86a87d7fc05576b563ca2b1dc79534da92c02b9a50e288f7aef`

OBJ는 연결된 원본 메쉬로 유지한다. 팔 절단, 손 크기 변경, 손 끝 길이 압축, 어깨의 일괄 비등방 축소는 현재 방식에서 제외했다. 리그의 국소 연결부 보정은 손과 아래팔, 머리와 몸 중앙에 영향을 주지 않도록 검증한다.

## v4에서 바로잡은 점

1. 손 반경 +12%, 손 끝 방향 길이 최대 -24% 보정을 삭제했다.
2. 어깨 폭·깊이를 강제로 축소하고 겨드랑이를 위로 밀던 처리를 삭제했다.
3. 기본 자세를 임의의 0.43rad로 좁히지 않고 원본 팔 축(깊이 포함)으로 되돌렸다.
4. 연결부만 번갈아 평활화한 뒤 짧게 마무리해 접힘을 완화한다. 보정 최대치는 약 4.99cm이며, 손·아래팔의 보정값은 0이다. 이는 전신 부피나 모든 포즈의 길이가 수학적으로 보존된다는 뜻은 아니다.
5. 손목이 먼저 움직이고 아래팔이 작게 따라오는 인사와 카메라 입력의 독립 손목 회전은 유지한다.

정지 그림과 실제 캔버스 녹화로 확인한다. 사용자 합격이나 실제 사람의 카메라 동작 검증을 대신하지 않는다.
