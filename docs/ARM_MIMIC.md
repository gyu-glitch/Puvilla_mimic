# 서 있는 푸빌라 팔 미믹 — v6 검토본

2026-10-20. v3~v5는 사용자에게 반려됐다. v5에서는 팔이 꺾인 것처럼 보인다는 지적을 받았다. v6는 팔꿈치 굽힘을 개선한 중간 후보이며, 어깨 아래 덩어리는 아직 남는다. 사용자 합격이나 작업 완료를 의미하지 않는다. 지속 작업 기록은 `CONTINUOUS_REVIEW.md`에 있다.

## 변경

- v6: 팔꿈치 방향을 길이의 36~60% 구간에서 연속적으로 바꾸고, 단위 접선을 적분한 중심선에 단면을 회전해 배치한다. 앞발 크기와 중심선 길이를 임의로 줄이지 않는다. 곡률에 따른 분석 법선으로 관절의 가로 띠 음영을 줄였다.
- v6: 정면·45도·측면, 큰 굽힘, 반대손 및 들기/인사/내리기12초를 검토했다. 실제 캔버스 녹화는 `arm-review/codex-v6-wave.mp4`, `arm-review/codex-v6-greet.mp4`다. 자동 검사에는 0~2.4rad 굽힘의 중심선 길이·접선 연속성·손 쪽 강체 구간을 추가했다.
- 아래 몸통 고정·구도·손목 제약은 v5에서 유지한 사항이다. 아래쪽 v5 영상/픽셀 측정은 v5 당시 결과로서 v6 전체 표면의 일치 증거는 아니다.
- 공식 연결 메쉬, 얼굴, 목도리, 털과 유화 필터를 유지한다. 원본 파일 해시만으로 최종 변형 형태를 보장하지 않는다.
- 팔 경계 바깥 몸통 1,372개 원본 정점을 고정한다. 이전에는 몸통 측 11cm 구간에도 팔 회전 가중치가 들어갔다. 이제 팔 쪽 18cm 구간에서만 연결을 보간한다.
- 어깨 연결부 보정도 몸통 고정 정점에 적용하지 않는다. 현재 최대 국소 보정은 8.71cm이며 손·아래팔 보정은 0이다. 모든 자세의 부피 보존을 주장하지 않는다.
- 인사 시 위팔은 고정하고 아래팔만 약 5도 이내로 흔든다. 손은 아래팔과 같은 방향을 유지한다. 인사 입력의 독립 손목 굽힘은 0이다.
- 실제 카메라 손목 입력은 최대 0.18rad로 제한했다. 손목의 짧은 구간에서만 연결하고, 그 이후 손은 하나의 회전으로 움직인다. 손 전용 추적 모델을 사용한 것은 아니다.
- 가로 화면은 원본 공개본의 중심 133cm, 높이 90cm, 카메라 경사 -6도로 복구했다. 세로 화면은 손을 볼 수 있도록 더 넓은 별도 구도(높이250cm, 중심133cm)를 쓴다. 구도가 완전히 동일한 것은 가로 화면이다.
