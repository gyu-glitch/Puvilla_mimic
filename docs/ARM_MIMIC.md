# 서 있는 푸빌라 팔 미믹 — v5 검토본

2026-10-20. v3 및 v4는 사용자에게 반려됐다. 특히 v4의 말랑하게 휘는 움직임과 달라 보이는 몸통이 지적됐다. 사용자 합격을 의미하지 않는 재검토본이다.

## 변경

- 공식 연결 메쉬, 얼굴, 목도리, 털과 유화 필터를 유지한다. 원본 파일 해시만으로 최종 변형 형태를 보장하지 않는다.
- 팔 경계 바깥 몸통 1,372개 원본 정점을 고정한다. 이전에는 몸통 측 11cm 구간에도 팔 회전 가중치가 들어갔다. 이제 팔 쪽 18cm 구간에서만 연결을 보간한다.
- 어깨 연결부 보정도 몸통 고정 정점에 적용하지 않는다. 현재 최대 국소 보정은 8.71cm이며 손·아래팔 보정은 0이다. 모든 자세의 부피 보존을 주장하지 않는다.
- 인사 시 위팔은 고정하고 아래팔만 약 5도 이내로 흔든다. 손은 아래팔과 같은 방향을 유지한다. 인사 입력의 독립 손목 굽힘은 0이다.
- 실제 카메라 손목 입력은 최대 0.18rad로 제한했다. 손목의 짧은 구간에서만 연결하고, 그 이후 손은 하나의 회전으로 움직인다. 손 전용 추적 모델을 사용한 것은 아니다.
- 가로 화면은 원본 공개본의 중심 133cm, 높이 90cm, 카메라 경사 -6도로 복구했다. 세로 화면은 손을 볼 수 있도록 더 넓은 별도 구도(높이250cm, 중심133cm)를 쓴다. 구도가 완전히 동일한 것은 가로 화면이다.

- 손목 굽힘 없는 인사, 위팔 고정, 작은 아래팔 회전, 좌우 미러링, 주기 연속성 및 가림 처리 검사 통과.
