# 서 있는 공개 모델 팔 미믹 — 2026-10-20 첫 검토본

## 문제와 변경

기존 원본 리그는 팔/몸통을 공간상의 반경으로 구분했다. 팔 안쪽이 몸통 내부에 겹쳐 들어가 있는 모델이므로 팔 표면 일부가 몸통으로 분류되고, 옆구리 일부는 팔로 분류된다. 큰 회전에서 옆구리가 막처럼 올라오는 현상을 검증 화면에서 재현했다. 기존 1.2rad 위팔 제한은 이 변형을 가렸지만 사람의 팔 각도도 따라가지 못하게 했다.

`scripts/build-standing-rig.mjs`는 원본 쿼드의 연결 관계에서 어깨 둘레와 팔 표면을 식별한다. 그 표면을 따라 가중치를 계산하고, 원본 메쉬와 동일한 Catmull–Clark 분할로 가중치도 보간한다. 메쉬를 자르거나 정점/면을 추가·이동하지 않는다. 몸 중앙과 머리는 팔 가중치 0을 유지한다. 관절은 실제 어깨 둘레 중심과 팔 중심선을 기준으로 좌우 대칭으로 배치했다.

부가 수정:

- 수평 위에서는 사람의 위팔 각도를 직접 따라간다. 팔을 내렸을 때만 원래 곰의 A자 자세로 보정해 배를 관통하지 않게 한다.
- 각 팔의 손목/팔꿈치 신뢰도를 독립적으로 처리한다. 가림은 500ms 유지 후 부드럽게 기본 자세로 복귀한다. 신뢰도 낮은 값이나 NaN을 필터에 넣지 않는다.
- 얼굴 대상이 없을 때 다른 사람의 가장 큰 몸을 임의로 따라가지 않는다.
- Codex 설정에서 Pose와 body를 켰다. 원래 공개 설정은 변경하지 않았다.

## 확인 주소

- 실제 카메라: http://localhost:4175/
- 자동 팔 입력 데모: http://localhost:4175/?sim=1&armdemo=1 (같은 리타기팅/렌더 경로, 카메라 사용 없음)
- 자세·시점·털 검증: http://localhost:5175/dev/arm-lab.html
- 기존 방식 비교: http://localhost:5175/dev/arm-lab.html?rig=legacy&pose=up

자동 데모에서는 팔이 보이도록 카메라만 넓힌다. 실제 미믹의 기본 구도는 원래 설정이다. 팔이 카메라에 들어오도록 어깨·팔꿈치·손목이 보이는 거리에서 실제 추적을 확인해야 한다.

## 검증과 한계

- 원본 OBJ 및 목도리 바이너리 SHA-256 일치.
- 가중치 범위/합, 머리·중앙 몸통 964개 원본 정점의 팔 가중치 0, 좌우 관절 대칭 검사.
- 미러링, 한쪽 팔 가림 유지/해제, NaN 복구, 얼굴/몸 대상 연결 검사.
- 타입 검사와 Vite 배포 빌드 통과.
- 브라우저에서 만세·팔꿈치 굽힘·수평 양팔 및 연속 입력을 관찰했다. 원래 배경·목도리·털·유화 필터에서도 표시된다.
- 실제 사람의 카메라 추적, 손바닥 방향, 극단적인 교차/비틀기, 장시간 성능은 아직 검증하지 않았다. 현재는 선형 스키닝이며 깊게 굽힌 관절의 부피 유지에는 추가 조정 여지가 있다.

실행: `npm run rig:build` → `npm run rig:check` → `npm run deploy` (모두 Codex 폴더에서).
