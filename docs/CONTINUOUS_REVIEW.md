## 이번 회차: 연속 곡률 팔꿈치

- pose-first 정지 후보는 정면/45도에서 약간 매끈하지만 어깨 아래가 낮고 둥근 덩어리로 남았다. 효과가 충분하지 않아 채택·배포하지 않았다.
- 별도 실시간 후보를 구현: `standingArmSurface.ts`의 `pvRoundedElbow`는 팔 길이의 36~60%에 걸쳐 방향을 부드럽게 바꾸고 단위 접선을 적분한 중심선으로 표면을 옮긴다. 중심선 밖의 단면은 회전만 하며, 전후 구간은 강체로 유지한다. 몸통의 0 가중치 영역은 제외한다. 골격의 인덱스4/5와6/7은 연결 서 있는 모델 전용이다.
- `standingBend.ts`는 같은 수학의 CPU 검증 기준이다. 0~2.4rad 굽힘에서 길이, 끝 접선 연속성, 손 쪽 강체 구간, 정확한 직선 복원을 검사한다.
- 최초 12점 중점 적분은 큰 굽힘에서 경계 접선 검사에 실패했다. 6점 Gauss-Legendre 적분으로 바꾼 후 검사 통과. 셰이더도 동일 노드/가중치를 쓴다.
- 굽힘 영역 법선을 실제 변형 표면으로 다시 계산한다. 내린 직선 자세에는 새 법선 혼합을 적용하지 않는다.
- 개발 브라우저에서 셰이더 오류 없고 정면 약56fps. 실제 모바일 하드웨어 성능은 아직 미검증.
- 캡처 접두사는 `codex-v6`, 정지 실험은 `codex-v6-posefirst`. `source=1`의 정지 모델은 녹화 버튼을 비활성화해 동작 증거로 오인하지 않도록 했다.
- 남은 핵심 결함: 어깨 아래 접힘/덩어리. 단일 인사 자세에서 만든 corrective를 다른 팔 각도에 그대로 회전해 쓰는 방식도 아직 개선 대상이다. 새 팔꿈치 곡선과 기존 어깨 보정의 겹치는 구간(t0.32~0.48)이 추가로 볼 지점이다.

- 추가 검토에서 삼각형별 법선 재계산이 팔꿈치에 가로 띠를 만들었다. 새 팔꿈치 구간은 중심선 곡률의 Jacobian으로 법선을 변환하도록 고쳤다. 기존 어깨 접합부 법선 처리는 유지했다.
- 큰 굽힘에서 안쪽이 접히지 않도록 굽힘 구간 폭을 36~60% 팔 길이 사이에서 각도에 맞춰 넓힌다. 앞발이 시작되기 전에 곡률은 0으로 돌아온다. 손 크기를 변경하는 처리는 없다.

- v6의 `dFdx/dFdy(vViewPosition)`는 삼각형마다 하나인 면 법선을 만들어 연결부가 겹친 고리처럼 보였다. 이 fragment 대체를 제거했다.

## v8 진행: 어깨 경계와 변형 순서

사용자 중지 지시는 없다. 아래 작업은 v7 이후이며 아직 합격/완료가 아니다. 가이드24/50쪽과 최초 손인사 이미지를 다시 직접 열어 대조했다.

### 폐기한 후보와 원인

- `arap`: 원본 몸통 경계 전부 고정 + 국소 ARAP. 뿌리가 얇게 조이고 최대 보정13.10cm. 미채택.
- `arapcap`, `arapsolid`, `araplift`, `araprelative`: 어깨 주변 일부 허용, 단면 내 거리 제약, 수직 이동 허용, 상대 엣지 변형 최소화 순으로 비교. 상대 제약은 늘어짐을 줄였지만 붙여 놓은 팔 같은 하단 덩어리가 계속 남았다. 미채택.
- `wrapsolve`: 새 경계에 ARAP 결합. 여전히 연결부 인상이 부족해 미채택. Python 실험은 `scripts/solve-shoulder-arap.py`, 입력 준비는 `prepare-shoulder-solve.mjs`에 보존했다.
- CPU 변형 없이 `wrap`/`wrapfair` 가중치만 변경하면 정면 하단은 좋아지지만 45/90도 가로 접힘은 남는다. 단순 가중치 수정만 채택하지 않는다.

### 실제 구현 중인 후보

- `--socket-wrap`: 연결된 원본 팔 경계 양쪽 8cm에 회전을 전달한다. 기존 고정1,372점 중 **국소 어깨 피부80점**에만 추가 영향이 생긴다. 고정점은1,292개이며 배·머리·몸 중앙은 고정한다. 이전의1,372점 고정 주장을 v8에 적용하지 않는다. 새 점 범위는 |x|18~33cm, y87~127cm 이내다. 이 경계 조정은 사용자에게 허가된 몸통 형태 보존을 달성하기 위한 구현 변경이며 몸 전체 확대/축소가 아니다.
- `wrapfair`는 새 경계에40회 교대 fairing+16회 마무리. 최대 국소 보정8.14cm. 손/아래팔 보정은0. 원본 OBJ와 목도리는 그대로다.
- 이 경계에서 **케이지를 먼저 움직이고 그 뒤 Catmull-Clark 세분화**하는 정지 실험이 사선 접힘을 줄였다. 이전 v6 pose-first 실패와 달리 새 경계에서 효과가 확인되어 실시간화했다.
- `StandingCageSurface`: 1,886점 연결 케이지에 DQ/손 회전/손목/어깨 보정을 적용한 후2단계 세분화한다. 위치와 면적 가중 법선을 실제 변형된 표면에서 구한다. 팔 영향 영역11,194개 렌더 정점만 데이터 텍스처로 덮어쓴다. 얼굴 및 비영향 영역은 기존 렌더 경로를 유지한다.
- `SubdivisionPlan`: 고정 토폴로지를 한번 준비하고 매 프레임 수치 배열만 평가한다. 원본 세분화와 동일한 경계/UV 정점 순서를 유지한다. 각 털 쉘에서 전체 변형을 반복하지 않고 계산된 표면을 공유한다.
- 처음 CPU DQ만 적용한 후보는 큰 굽힘에서 팔꿈치가 뭉툭해졌다. 기존 v6의 단위 접선 적분 곡률을 **케이지 단계**에 결합했다. 이 결과의 증거 접두사는 `codex-v8-rounded-cage-*`다. DQ만인 `codex-v8-cage-*`와 구분한다.
- 기존 surface 셰이더의 rounded elbow 혼합이 raw arm mask만 보고 목/몸통 bone weight를 무시하던 결함도 수정했다. 실제 팔 bone weight와의 최솟값을 사용한다.
